# Domains

Business concepts, independent of any particular implementation. These docs
describe **what** the product is about (the domain model and its language),
not **how** the code is structured — for that, see
[`../architecture/`](../architecture/).

Terminology is curated in the [glossary](../context/terminology.md). Domain docs
reference the glossary but keep the canonical definitions close to the concepts.
